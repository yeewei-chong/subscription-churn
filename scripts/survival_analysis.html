Loading Data

Joining the members and events tables, using data in or after 2015. Low-frequency cities and registration methods are grouped under OTHER. The three most popular tiers, namely NT\$99, NT\$129, and NT\$149, are chosen to compare.

df <-dbGetQuery(con, "
  SELECT 
      events.member_id,
      city, 
      registration_method, 
      is_complete_age_gender, 
      tenure_id, 
      avg_price, 
      start_day, 
      end_day,
      event
  FROM events
  INNER JOIN members
  ON events.member_id = members.member_id
  WHERE avg_price IN (99, 129, 149)
    AND registration_date >= '2015-01-01 00:00:00';
"
) %>%
  add_count(city, name = 'city_count') %>%
  add_count(registration_method, name = 'regis_count') %>%
  dplyr::mutate(
    city = if_else(city_count/n() < 0.05,
                   "OTHER",
                   city),
    registration_method = if_else(regis_count/n() < 0.05,
                                  "OTHER",
                                  registration_method),
    pricing_tier = as.character(avg_price)
  ) %>%
  select(-city_count, -regis_count)

The Model

A Cox Proportional Hazards Model is used, with the price and city as covariates. An interaction between them is also introduced.

\[ h(t) = h_0(t)\cdot\exp\left[\beta_1\text{pricing\_tier} + \beta_2\text{city} + \beta_3(\text{pricing\_tier}\cdot\text{city})\right] \]

Plotting the Schoenfeld residuals against time, it can be seen that all the residuals stay relatively constant up till 365 days. That means that there is no evidence against the proportional hazards assumption.

cox_fit <- coxph(surv_obj ~ pricing_tier*city, data = df)
plot(cox.zph(cox_fit))
